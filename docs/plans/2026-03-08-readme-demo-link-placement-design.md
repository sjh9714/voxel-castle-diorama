# README 데모 링크 위치 조정 설계 메모

## 배경

현재 README에는 GitHub Pages 데모 링크가 하단 `링크` 섹션에 있다. 사용자는 이 링크를 `소개` 섹션 안으로 옮기길 원한다.

## 목표

- 데모 주소가 문서 초반에 더 빨리 보이게 한다.
- README 구조는 그대로 유지한다.
- 같은 데모 링크가 두 군데에 반복되지 않게 한다.

## 접근안

### 1. 소개 제목 바로 아래에 한 줄 링크 배치

- 장점: 가장 빨리 보인다.
- 장점: 문장 안에 섞이지 않아 읽기 쉽다.
- 단점: 소개 문단 앞에 한 줄이 추가된다.

### 2. 소개 문단 첫 문장에 링크 포함

- 장점: 텍스트 흐름이 자연스럽다.
- 단점: 링크가 눈에 덜 띈다.

### 3. 링크 섹션 유지

- 장점: 구조 변경이 거의 없다.
- 단점: 사용자가 원하는 위치가 아니다.

## 선택

1번을 선택한다. 사용자는 `소개란에 넣어줘`, `1 하고 푸시`라고 승인했다.

## 세부 설계

- `## 소개` 바로 아래에 `데모: ...` 한 줄을 추가한다.
- 하단 `## 링크` 섹션에서는 저장소 링크만 남긴다.
- 테스트는 README에서 `## 소개` 다음에 데모 링크가 나타나는지 확인한다.
