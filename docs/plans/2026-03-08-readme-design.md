# README 디자인 메모

## 배경

이 저장소는 단일 `index.html`로 구성된 Three.js 복셀 성 디오라마 프로젝트다. 공개 저장소까지는 만들어졌지만, 포트폴리오 문맥에서 바로 읽히는 한국어 README가 없다.

## 목표

- 저장소 첫 화면에서 프로젝트 성격이 바로 보이게 한다.
- 설명은 짧게 유지하되, 구현 포인트와 실행 방법은 놓치지 않는다.
- 과장된 문구 대신 담백하고 자연스러운 한국어를 쓴다.

## 접근안

### 1. 최소형

제목, 한 줄 소개, 기술 스택만 둔다.

- 장점: 가장 짧고 깔끔하다.
- 단점: 작업 내용과 조작 방식이 충분히 드러나지 않는다.

### 2. 포트폴리오형

짧은 소개 뒤에 핵심 특징, 조작 방법, 실행 방법, 사용 기술, 링크를 둔다.

- 장점: 채용 담당자나 방문자가 빠르게 훑기 좋다.
- 단점: 최소형보다 약간 길어진다.

### 3. 개발 기록형

구현 포인트와 테스트 방식까지 자세히 쓴다.

- 장점: 기술 설명이 풍부하다.
- 단점: 포트폴리오 README로는 무겁다.

## 선택

2번 포트폴리오형을 사용한다. 사용자는 "깔끔하고 심플한 포트폴리오용" 방향을 승인했다.

- 포트폴리오 소개문처럼 단정한 톤 유지
